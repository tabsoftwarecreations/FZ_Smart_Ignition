# FZ Smart Ignition

ESP32 BLE based smart ignition system for motorcycle control.

## Features

* Bluetooth Low Energy (BLE)
* LOCK / UNLOCK commands
* ESP32 command processing
* Future relay integration
* Manual key system retained as backup

## Hardware

* ESP32 Dev Module
* 5V Relay Module
* LM2596 Buck Converter
* LEDs
* Fuse Protection
* SPDT Override Switch

## Progress

* Phone connection ✅
